This set of scripts was used to run [FastQC](https://www.bioinformatics.babraham.ac.uk/projects/fastqc/), [fastp](https://github.com/opengene/fastp), and [breseq](https://barricklab.org/twiki/bin/view/Lab/ToolsBacterialGenomeResequencing) on My's data from the _S. epiderimidis_ genomic deletion project. 

breseq output files for the 50 samples run in population mode and RP62a run in clonal mode are located in [**workflow/breseq/output**](https://github.com/DoranG1/staph-epi-genomic-deletion/tree/main/workflow/breseq/output). Individual .csv files are in the directory for each sample, while a concatenated .csv file is at [**workflow/breseq/output/combined.csv**](https://github.com/DoranG1/staph-epi-genomic-deletion/blob/main/workflow/breseq/output/combined.csv). The full set of breseq outputs and intermediates is at **RDrive/DoranGoldman/staph-epi-genomic-deletion/breseq**.

The ([**workflow/mutationProfiling**](https://github.com/DoranG1/staph-epi-genomic-deletion/tree/main/workflow/mutationProfiling) directory contains scripts that subtract the mutations identified in RP62a_P0 run in clonal mode from the 50 samples run in population mode. Both individual .csv files and the concatenated .csv file are in [**workflow/mutationProfiling/output**](https://github.com/DoranG1/staph-epi-genomic-deletion/tree/main/workflow/mutationProfiling/output).

All output and intermediate files are in **RDrive/DoranGoldman/staph-epi-genomic-deletion**. These include the FastQC outputs on the raw data, the fastp outputs, FastQC outputs on the fastp outputs (in **fastqc2** directory), and the breseq outputs and intermediates.
